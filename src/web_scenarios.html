Explore one input across a range

Keep a base profile fixed and vary one numeric field across evenly spaced values. This shows how the model responds to hypothetical inputs, not what changing a habit would cause or what treatment to choose.

$feedback
Base patient profile
$fields
Scenario range

All base profile fields must be valid. Both endpoints are included. Scenario values replace the chosen base field; all other fields remain fixed. Decimal values are allowed.

Runs locally. The server does not store the scenario profiles. Download the CSV to keep the complete inputs and predictions.
