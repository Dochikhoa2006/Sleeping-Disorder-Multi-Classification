Build a new CSV

  1. Download the blank template and keep the header names unchanged.
  2. Add one patient per row, filling every required field. Save as UTF-8 CSV.
  3. Open the batch upload form to preview predictions and download the completed results.

The blank template contains only a header; add at least one patient before uploading. For a working demonstration, download the synthetic example CSV.

Extra columns such as record IDs are preserved. Headers must be unique and non-empty. Omit any existing “Predicted Sleep Disorder” column before prediction. Quote CSV values that contain commas or line breaks.

Numeric fields must contain numbers without unit suffixes. Categorical text is trimmed before preprocessing; unfamiliar categories may be accepted but acceptance does not establish model reliability.
