Compare two prediction exports

Match records by their exact Record ID, regardless of row order. Find changed predictions, changed inputs, and IDs added or removed between batches.

$feedback

Use full prediction exports containing the 11 patient fields, a unique non-empty Record ID, and Predicted Sleep Disorder. Both files together must be under 2 MiB including upload overhead.

$results

Comparison runs locally without loading a model or storing either upload. The download includes all IDs, including unchanged records, in baseline order followed by new candidate IDs.

Changed input profiles are reported separately from prediction changes on equivalent inputs. Comparison uses the same input normalization as the model and ignores extra columns. This compares exported results; it does not measure accuracy or identify the cause of a change.
